# 🚗 Self-Driving Car using AI and Computer Vision

## 📌 Overview
This project implements a Self-Driving Car system using Artificial Intelligence, Computer Vision, and Deep Learning techniques. The model is designed to perceive the surrounding environment, detect lane markings, recognize traffic signs, and predict steering commands for autonomous driving.

The objective of this project is to simulate the core functionalities of an autonomous vehicle while demonstrating the practical application of machine learning in transportation.

---

## ✨ Features

- 🚗 Autonomous steering prediction
- 🛣️ Lane detection
- 🚦 Traffic sign recognition
- 👀 Real-time camera input processing
- 🧠 Deep Learning based decision making
- 📊 Performance evaluation and visualization
